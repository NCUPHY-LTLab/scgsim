# SGB design figures

The figures of `docs/design/sgb/*.qmd` are generated by the scripts in this folder.
The site render never runs them; run them by hand and commit the outputs in
`../figures/`.

Run every script from the package root with the project environment:

```bash
PY=.venv/bin/python
$PY docs/design/sgb/_figures/<script>.py
```

Each script puts the prototype (`experiments/sgb-redesign/prototype`) on `sys.path`, reads
its `outputs/` or rebuilds the model with `sgbproto`, writes a Plotly HTML (sharing the one
`../figures/plotly.min.js`) and a static SVG with the same base name, and writes a small
`<page>-numbers.json` with the numbers the page quotes. Set `SGB_QA_DIR` to a folder to also
get a PNG copy of every SVG for a quick look.

Output file names start with the page prefix (`index-`, `why-`, `layered-`, `arrangement-`, ...).

## Overview, why plan first, layered model, arrangement

| Script | Writes | Shows |
|---|---|---|
| `_intro_common.py` | none | shared helpers: prototype path, palette, SVG and Plotly writers, section and cell drawing |
| `index_example.py` | `index-example-input.svg`, `index-example-3d.html/.svg`, `index-numbers.json` | the pad-in-ground prisms (plan and x-z section) and the exploded volumes derived from them |
| `why_scaling.py` | `why-scaling.html/.svg`, `why-tail.html/.svg`, `why-scaling-numbers.json` | measured time and memory against N, and the time from topology to a loadable model at N = 20000; identity digests across tile and worker counts |
| `why_structure.py` | `why-structure.html/.svg`, `why-structure-numbers.json` | counted structure (box pairs, host-face wires, coplanar faces) of a solids-first model; no Boolean operation is run |
| `layered_model.py` | `layered-stack.svg`, `layered-exploded.html/.svg`, `layered-slab-vs-level.svg`, `layered-walls.svg`, `layered-numbers.json` | levels, slabs and active sets; prisms to levels to slabs; slab and level arrangements; wall coalescing |
| `layered_phantom.py` | `layered-phantom.html/.svg`, `layered-phantom-numbers.json` | a 3 nm sliver in a global projection of two unrelated layers, absent from the local arrangements |
| `arrangement_steps.py` | `arrangement-steps.html/.svg`, `arrangement-steps-numbers.json` | iterated snap rounding on five carriers: hot pixels, rounds, noded edges, DCEL faces |
| `arrangement_guarantees.py` | `arrangement-guarantees.html/.svg`, `arrangement-complexity.html/.svg`, `arrangement-arc-witness.svg`, `arrangement-guarantees-numbers.json` | measured guarantees and deviation, cost against size, the polyline witness of an arc |

## Emission (`emission.qmd`, `brep-format.qmd`)

| Script | Writes | Shows |
|---|---|---|
| `emission.py` | `emission-timing.html/.svg`, `emission-shared-face.svg`, `emission-groups-3d.html/.svg`, and the markdown tables `emission-{counts,timing-api,timing-direct,timing-load,timing-workers,tags,groups,validation,step}-table.md` | write and load cost of the gmsh-API emitter against the direct writer (from `outputs/e3_brep/timing.json`); one face shared by two shells; the reopened `pad_in_ground_B.xao` coloured by physical group; the tables the page includes with `{{< include >}}` |
| `emission_snippets_check.py` | none | checks that every quoted file excerpt on both pages (blocks headed `filename="model.brep, lines a-b"`) is equal to those lines of the E3 outputs; exit status 1 on a mismatch |

`emission.py` reads `outputs/e3_brep/**` and rebuilds `pad_in_ground_B` to check that its planned-id to tag numbering still equals the recorded `tags.json`; it stops if the prototype's numbering has changed. Run it after `examples/brep_emit.py` (and `--timing`) and re-run the snippet check after editing the page.

## Inset imprint, identity, parallelism (`inset-imprint.qmd`, `identity.qmd`, `parallelism.qmd`)

| Script | Writes | Shows |
|---|---|---|
| `inset_kit.py` | none | helpers shared by the three scripts below: prototype and output paths, the palette, one scene description (lines, polygons, points, labels in panels) drawn as a Plotly HTML (shared `plotly.min.js`) and as an SVG, and the `SGB_QA_DIR` PNG copy |
| `inset.py` | `inset-erosion-construction`, `inset-bands-pad`, `inset-arcs-vs-polygon`, `inset-topology-change` (each `.html` + `.svg`), `inset-mask-vs-imprint.svg/.json`, `inset-routes-section.svg`, `inset-tables.md` | the corner rule on margins 1.5, 3 and 6 µm; the bands of the running example (margins 0.1, 0.5, 2 µm); exact arcs against a KLayout 512-gon; the neck split and the empty band (margins 4, 9, 30 µm); a 2-D gmsh illustration of an element cut by a mask against a mesh aligned to the contour (illustration, not a Palace run); a conceptual cross-section of Route A and Route B; the band-area, KLayout, Palace-check and Route B (both faces banded) tables quoted by the page |
| `identity.py` | `identity-trace-plan.html/.svg`, `identity-trace.json`, `identity-determinism.json`, `identity-stability.json`, `identity-tables.md` | the lookup Palace attribute 7 to a source curve on `pad_in_ground_B_bands`, read from the direct writer's `sgbproto-sidecar-2` (it asserts that the rebuilt groups equal the stored `identity.json` and the sidecar); one build digest per (tiles, workers, `PYTHONHASHSEED`) in fresh interpreters; which IDs survive removing the port |
| `parallel.py` | `parallel-tiles.html/.svg`, `parallel-speedup.html/.svg`, `parallel-tables.md` | between-pixel tile ownership of the running example for 2×2, 3×3, 4×4 tiles plus a conceptual pixel zoom; speed-up, Amdahl curve and stage times from the prototype's `outputs/scaling.json` (nothing is re-measured), with every range quoted on the page |

`inset.py` and `identity.py` rebuild models with the prototype (about 10 s each); `parallel.py` only recomputes tile ownership.
The page `pipeline-reference.qmd` and `decisions.qmd` have no figures; their numbers come from the prototype outputs named in the text.

## Labels, assembly, routes, cut families, slivers, validation (`labels-and-dissolution.qmd`, `assembly.qmd`, `routes.qmd`, `cut-families.qmd`, `slivers.qmd`, `validation.qmd`)

| Script | Writes | Shows |
|---|---|---|
| `labels_common.py` | none | helpers shared by the six scripts below: prototype path, palette, SVG and Plotly writers, cell and edge drawing, compact face triangulation for 3D views |
| `labels_and_dissolution.py` | `labels-slab-cells.svg`, `labels-level-links.html/.svg`, `labels-dissolution.html/.svg`, `labels-numbers.json` | slab labels of Route B and the prisms covering each cell; level labels by linking at z = 0, 0.1, 0.2; one slab of the running example plus a same-Net tab before and after dissolution; the two overlap errors; area membership of the merged pad cell |
| `assembly.py` | `assembly-wall-anatomy.svg`, `assembly-shells.html/.svg`, `assembly-inner-void.svg`, `assembly-numbers.json` | the walls along three pad sides as built and with coalescing disabled (it patches `assembly._level_cuts_wall` for that build and restores it); the 24 shell faces of the airbridge `Ground` volume pulled apart; a floating island that gives the vacuum an inner shell |
| `routes.py` | `routes-cells.html/.svg`, `routes-3d.html/.svg`, `routes-numbers.json` | the same five cells of Route A (z = 0) and Route B (z = 0.1) with their groups, the other Route B levels, both models as exploded volumes, side-by-side counts |
| `families.py` | `families-level.html/.svg`, `families-numbers.json` | level z = 0 with port, inset bands, a `required` window family and a `refinement_only` curve, edges coloured by family; counts of each family added alone; band areas with and without the extra families; build identity with the family list reversed |
| `slivers.py` | `slivers-gallery.html/.svg`, `slivers-numbers.json` | one computed example per sliver source (three near-concurrent curves; two unrelated layers 4 nm apart with the old global projection emulated by a `required` family; a 2 nm same-Net overlap; a 5 nm gap ring; a derived band curve 4 nm from a source curve, with derived-to-source snapping emulated); report entries; a whole-model 10 nm grid as a stand-in for a coarser snap grid |
| `validation.py` | `validation-shell.html/.svg`, `validation-tampered-shell-report.json`, `validation-numbers.json` | the vacuum shell without its top face and the edges it now uses once; the full validation report of that model; eight deliberate defects and the checks that fail for each; the two errors that stop a build before validation |

All six rebuild models with the prototype (`build()`), take a few seconds each, and never edit the prototype.
