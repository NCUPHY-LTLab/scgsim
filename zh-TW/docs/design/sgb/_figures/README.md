# SGB design figures

The figures, tables and numbers of `docs/design/sgb/*.qmd` are generated by the scripts in this folder from the production
package `scgsim.geometry.sgb` (branch `claude/sgb-core`).  The site render never runs them; run them by hand and commit the
outputs in `../figures/`.

## Running a script

Point `SGB_CORE` at a checkout that contains `scgsim.geometry.sgb` with its `tests/` folder, and run the script from the
repository root with **that checkout's** interpreter:

```bash
SGB_CORE=<sgb-core checkout>
SGB_CORE=$SGB_CORE $SGB_CORE/.artifacts/env/bin/python docs/design/sgb/_figures/<script>.py
```

The test-side builders are imported from `$SGB_CORE/tests`, which the scripts put on `sys.path` at run time; nothing of them is
copied.  Three kinds of input are used, and each row below says which:

* **real input** -- `tests/sgb_inputs.py`: `gds_pad_in_ground` (a GDS and a stack file, a 100 um die, a ground plane with a 40 um
  cutout, a 20 um pad, a lumped port on the substrate surface z = 0) and `thin_film_pair` (two sheets joined by a port), interpreted by
  the source stages S0 to S2 and built with `build_sgb_geometry` or `build_model_from_catalogue`;
* **stage-level scene** -- `tests/sgb_scenes.py` (`pad_in_ground`, `airbridge`, `random_layout`, `slab_model`) and `tests/sgb_emit_cases.py`
  (`CASES`): hand-made prism catalogues that exercise a stage (arcs, a mid-plane port, floating layers, random layouts);
* **measured run** -- `why_scaling.py`, `emission.py --measure`: a time or memory taken on the machine that ran it.

Output file names start with the page prefix (`index-`, `why-`, `layered-`, `arrangement-`, ...).  Each figure script writes a
Plotly HTML (sharing the one `../figures/plotly.min.js`) and a static SVG with the same base name, and a small `<page>-numbers.json` with the
numbers the page quotes.  Set `SGB_QA_DIR` to a folder to also get a PNG copy of every SVG for a quick look.

## Overview, why plan first, layered model, arrangement

| Script | Input | Writes | Shows |
|---|---|---|---|
| `intro_common.py` | none (helper) | none | shared helpers: production import path, palette, SVG and Plotly writers, the running example as a prism catalogue, section and cell drawing |

| `why_scaling.py` | measured run: Route B `random_layout` (seed 2, pitch 260 um), N = 1000, 5000, 20000, nine tile and worker schedules, each case in its own interpreter; the Gmsh-API oracle `tests/sgb_gmsh_oracle.py` at N = 500, 1000, 2000 | `why-scaling-measured.json`, `why-scaling-oracle.json`, `why-validator-scaling.json` (the three measuring modes), `why-scaling.html/.svg`, `why-tail.html/.svg`, `why-scaling-numbers.json` (plot mode) | measured time and memory against N, the time from topology to a loadable model at N = 20000, the time of each structural check, identity digests across tile and worker counts |

| `why_scaling_figures.py` | none (helper of `why_scaling.py`) | none | the plotting half: the scaling and tail figures and `why-scaling-numbers.json` |
| `why_structure.py` | stage-level scene: Route B `random_layout`; counts only, no Boolean operation is run | `why-structure.html/.svg`, `why-structure-numbers.json` | counted structure (box pairs, host-face wires, coplanar faces) of a solids-first model |

| `layered_phantom.py` | stage-level scene: two unrelated metal layers, built with `build_model_from_catalogue`, against one global snap-rounded arrangement of all footprints | `layered-phantom.html/.svg`, `layered-phantom-numbers.json` | a 3 nm sliver in a global projection of two unrelated layers, absent from the local arrangements |
| `arrangement_steps.py` | five exact integer carriers run through the production noding kernels round by round | `arrangement-steps.html/.svg`, `arrangement-steps-numbers.json` | iterated snap rounding on five carriers: hot pixels, rounds, noded edges, DCEL faces |

## Emission (`emission.qmd`, `brep-format.qmd`, `aedt-handoff.qmd`)

| Script | Input | Writes | Shows |
|---|---|---|---|
| `emission.py` | the pad-in-ground scene of `tests/sgb_scenes.py` under Route B with its port on z = 0, written with `emit_model` and reopened in Gmsh; `--measure` reruns the timings, `--measure-only` and `--occt-only` run one part | `emission-timing.html/.svg`, `emission-shared-face.svg`, `emission-groups-3d.html/.svg`, `emission-timing-data.json`, `emission-example-numbers.json` and the markdown tables `emission-*-table.md` | write and load cost of the Gmsh-API oracle against the direct writer, one face shared by two shells, the reopened XAO coloured by physical group, the tables the page includes with `{{< include >}}`; reads the shared `why-scaling-measured.json` |
| `emission_common.py`, `emission_figures.py`, `emission_tables.py`, `emission_checks.py`, `emission_measure.py` | none (helpers of `emission.py`) | none | the output paths and the running example; the figures; the counts, tag, group and timing tables; the oracle, loaded-model, validation, band and OCCT tables; the measuring children (`emission.py --head-one N`, `--validator-one N` run them) |
| `emission_snippets_check.py` | the same running example written by `emit_model` into scratch folders, with the Python of `SGB_CORE` | none | checks that every quoted file excerpt on `emission.qmd` and `brep-format.qmd` (blocks headed `filename="model.brep, lines a-b"`) equals those lines of the written files; exit status 1 on a mismatch |

`emission-step-table.md` is not written by `emission.py`: it is the E3 STEP round trip (`aedt-handoff.qmd` includes it) and stays as recorded.
`emission.py` needs OCP (the `occt` dependency group of the SGB core) for the OCCT tables.

| Script | Input | Writes | Shows |
|---|---|---|---|

| `labels_and_dissolution.py` | real input `gds_pad_in_ground`, Route B; one extra polygon on the `pad` entity for the dissolution example; the stage-level scene `pad_in_ground("B")` only to count merged chord edges | `labels-slab-cells.svg`, `labels-level-links.html/.svg`, `labels-dissolution.html/.svg`, `labels-numbers.json` | slab labels and the prisms covering each cell; level labels by linking; one slab plus a same-Net tab before and after dissolution; the two overlap errors; area membership of the merged pad cell |
| `assembly.py` | real input `gds_pad_in_ground`, Route B; stage-level scenes `pad_in_ground("B")` (arcs, mid-plane port) and `airbridge()`; the "every level cuts every wall" build patches `assembly.walls._level_cuts_wall` and restores it | `assembly-wall-anatomy.svg`, `assembly-shells.html/.svg`, `assembly-inner-void.svg`, `assembly-numbers.json` | the walls along three pad sides as built and with coalescing disabled; the shell faces of the airbridge `Ground` volume pulled apart; a floating island that gives the vacuum an inner shell |

## Consumer contract (`consumer-contract.qmd`, `consumer-mapping.qmd`)

| Script | Input | Writes | Shows |
|---|---|---|---|
| `consumer_contract.py` | the files of `experiments/sgb-redesign/consumer-contract/generate_excerpt.py`, which builds `gds_pad_in_ground` (Routes B and C), `thin_film_pair` (Route A) and the all-interfaces case with `build_sgb_geometry` and writes `out/` (git-ignored); the script only reads `out/` | `consumer-excerpt-{head,groups,unions,embeds,body,routea,routec}.md`, `consumer-palace-rebuild.md`, `consumer-aedt-rows-table.md`, `consumer-run-table.md`, `consumer-files-table.md` | real excerpts of the production sidecar `scgsim.sgb.sidecar.v1` of a tiny model, the Palace group dict rebuilt by the sidecar test's own `palace_style_groups`, the AEDT rows per group, the result of `verify_loaded`, `apply_sidecar_embeds` and `export_aedt_step`, and the file sizes |

Run the generator first, then the script, both with the interpreter of `SGB_CORE`:

```bash
SG=<sgb-core checkout>
$SG/.artifacts/env/bin/python experiments/sgb-redesign/consumer-contract/generate_excerpt.py $SG/tests experiments/sgb-redesign/consumer-contract/out
$SG/.artifacts/env/bin/python docs/design/sgb/_figures/consumer_contract.py
```
